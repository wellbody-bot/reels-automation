  시점에 앞당겨 구현).

  매주 월요일 08:30 실행, `scripts\run_weekly.ps1`이 파이썬 스크립트를
  호출하고 `output\logs\`에 실행 로그 저장. 다음 실행: 2026-09-07 08:30.
  (원 계획서는 Phase 2 Task 2-2에서 스케줄링 예정이었으나 사용자 요청으로

- 실행 주기는 "주간 + publishedAfter 7~14일" 조합으로 결정 — 실시간 트렌드
  포착보다 이미 검증된 급상승 영상 벤치마킹이 목적이라 잦은 실행의 실익이
